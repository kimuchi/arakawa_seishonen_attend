1

認証 (Application Default Credentials)

このアプリは JSON キーを使わず、Application Default Credentials (ADC) を利用します。
  • Cloud Run / GCE / GKE: ランタイムサービスアカウントを Cloud Run に紐付けるだけ。アプリ側では自動検出されます。
  • ローカル開発: gcloud auth application-default login を 1 回実行。
  • その他: Workload Identity Federation など。詳しくはデプロイガイド参照。
下に表示されている「使用中のアカウント」が、スプレッドシートにアクセスするアカウントです。
このメールアドレスを、対象スプレッドシートに 「編集者」 として共有しておいてください。

2

スプレッドシートの指定

既存のスプレッドシートを使う場合は ID を入力してください (URL の /d/【ここ】/edit 部分)。
新規に作成する場合は「新規スプレッドシートを作成」ボタンを押すと、上記アカウントのドライブに作成されます。
新規作成時は「共有先メールアドレス」に普段使う Google アカウントを入れておくと、作成と同時に編集権限が付与されます。
3

ICS取込URL (任意)

Googleカレンダーの「秘密アドレス(iCal)」やシステムから発行されるICSフィードのURLを入れると、イベント管理タブから1クリック取込ができます。
未設定でもアプリは利用可能。あとから設定タブで変更できます。
4

設定を保存

設定は に書き込まれます。
保存と同時にスプレッドシートの初期化(シート構築 + 初期データ投入)を実行します。
